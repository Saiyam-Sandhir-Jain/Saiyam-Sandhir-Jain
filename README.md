### 🧠 What I work on

I build **backend systems and AI infrastructure** — from RAG pipelines and LLM tooling to versioned knowledge bases and data engineering backends. Recent focus areas:

- **Generative AI** — LLM-powered applications, prompt engineering, multi-modal pipelines (text + image generation)
- **Agentic AI** — tool-using agents, orchestration with LangChain, autonomous workflows built on top of RAG and LLM infrastructure
- **RAG & LLM Infrastructure** — retrieval pipelines, quantized inference, vector DB abstraction layers
- **Backend & Systems Design** — microservices, API gateways, auth, caching
- **Applied ML Research** — neuro-symbolic RL, NLP, published & open-sourced work
